## 1. Get a key

Create a workspace at [app.usegoro.ai](https://app.usegoro.ai) and generate an
API key. New workspaces start with a small promotional balance, so you can make
real calls before adding a card.

Keys look like `goro_live_...` and go in an `Authorization` header.

## 2. Find a tool

You do not need to know the catalog. Describe what you want:

```bash
curl -X POST https://api.usegoro.ai/v1/discover \
  -H "Authorization: Bearer $GORO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "tweets about ai agents"}'
```

Each result carries a slug and a price. Prices read as a ceiling, never an
exact figure, because a call is billed on what it actually consumes.

## 3. See what it takes

```bash
curl -X POST https://api.usegoro.ai/v1/inspect \
  -H "Authorization: Bearer $GORO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"slug": "web.search"}'
```

`inspect` returns the tool's real input schema and a `sample_input` you can
send as-is.

<Note>
  Goro forwards your input to the underlying tool and hands back its rows
  untouched. The schema you see in `inspect` is the real one, not a translation,
  so anything the tool accepts, you can send.
</Note>

## 4. Run it

```bash
curl -X POST https://api.usegoro.ai/v1/run \
  -H "Authorization: Bearer $GORO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "slug": "web.search",
    "input": { "queries": "best espresso machines", "maxPagesPerQuery": 1 }
  }'
```

A fast call returns `200` with the rows. A slower one returns `202` with a
`run_id`, and you poll `GET /v1/runs/{run_id}` until it completes.

## 5. Connect an agent instead

If you are using Claude, Cursor or another MCP client, skip the HTTP API and
add Goro as a connector:

```
https://mcp.usegoro.ai
```

The client will walk you through authorising it. Your agent then sees
`discover_tools`, `inspect_tool`, `run_tool`, `get_run` and `wallet_balance`,
and can find and call anything in the catalog on its own.
