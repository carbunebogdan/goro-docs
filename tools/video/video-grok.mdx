Generate a video from a text prompt using xAI Grok Imagine, at 720p with sound, or animate a still image you supply. Returns the URL of the generated MP4. That URL is temporary: kie.ai deletes generated media after 14 days and Goro holds a run's results for 24 hours, so collect what you need within 24 hours.

<Note>Use when you need motion cheaply or at volume: drafts, moving backgrounds, quick social clips, or ten takes on an idea before committing to an expensive model. By far the cheapest video model in the catalog, and it takes the longest clips (up to 30 seconds). It is also the cheapest way here to ANIMATE A PHOTOGRAPH, at a sixth of what video.kling costs per second and with no minimum length, and an image costs exactly the same per second as a text prompt. You can send that image as a link or inline as base64; base64 is the one to reach for when the file is local or private, because nothing is published to reach it. Billed per second of video you ask for.</Note>

## Price

**$0.0450 per second of video.** An exact rate, not an estimate. The total is that rate times the seconds of video in your request, so you can work out what a call costs before you make it.

No call costs less than $0.0020 or more than $1.35, the price of the largest request this endpoint takes, 30 seconds of video. `discover` and `inspect` quote your exact request before it runs.

## Input

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `prompt` | `string` | yes | What to film. Describe the subject, the action, the camera move and the timing. |
| `duration` | `integer` |  | Length of the generated video in seconds. This is what you are billed on, and it is the only field that changes the price. Defaults to `6`. |
| `image_urls` | `array` |  | Optional. One public http or https link to the image the video should start from (JPEG, PNG or WEBP, up to 10 MB). Supplying it makes this an image-to-video call, at exactly the same price per second. The output URL of an image endpoint works directly. If the image is a local or private file, use image_base64 instead and it never has to be published anywhere. Send one of the two, never both. |
| `resolution` | `720p` |  | Fixed at 720p. Resolution changes the price per second, and this endpoint quotes one exact rate, so 480p would get its own endpoint. Defaults to `"720p"`. |
| `aspect_ratio` | `1:1`, `2:3`, `3:2`, `16:9`, `9:16` |  | Shape of the output video. Defaults to `"16:9"`. |
| `image_base64` | `string` |  | Optional. The starting image sent inline, as base64 of the file's own bytes. A data:image/png;base64, style prefix is accepted and its declared type is ignored. USE THIS FOR A LOCAL OR PRIVATE FILE: nothing is published. The bytes are uploaded to a private bucket that has no public read and no address that works unsigned, handed to the model as an unguessable link that expires in 30 minutes, and deleted on a schedule shortly after. Up to 3 MB of image, which is 4,194,304 base64 characters; anything larger belongs on a link. JPEG, PNG or WEBP, checked against the file's own leading bytes rather than against any type you declare. Send this or image_urls, never both. |

<Note>
  These are all the fields this endpoint accepts. Anything else is rejected as
  a `validation_error` rather than forwarded to the provider.
</Note>

## Example

```bash
curl -X POST https://api.usegoro.ai/v1/run \
  -H "Authorization: Bearer $GORO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"slug":"video.grok","input":{"prompt":"A paper boat drifting across a still pond, slow push in."}}'
```

## Response

The full response. Values are illustrative.
